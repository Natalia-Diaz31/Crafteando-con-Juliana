# Crafteando-con-Juliana
Proyecto de desarrollo de un sistema web de gestión de planillas para Banco, enfocado en simplificar la creación y administración de nóminas mediante plantillas predeterminadas, centralización de información de empleados y validación de datos salariales, reduciendo errores y optimizando los procesos internos.
